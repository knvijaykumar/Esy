# Esy FARM Application

This project is separated into a dedicated frontend and backend.

## Project Structure
- `frontend/`: React + TypeScript + Vite UI application.
- `backend/`: FastAPI backend and API routes.
- `ml/`: Time-series forecasting and ML modules.
- `supabase/`: Database schemas and migrations.

## Getting Started

You can run both environments from the root directory:

**Frontend Dev Server**
```bash
npm run dev:frontend
```

**Backend Dev Server**
```bash
npm run dev:backend
```

**Frontend Build**
```bash
npm run build
```
